The Midnight Vault — a top-down 2D heist game: sneak past patrolling guards and sweeping cameras, crack the vault, grab the loot, and escape before the police countdown runs out. Three floors of escalating difficulty, alert meter, scoring, and synthesized WebAudio sound.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Move with WASD or arrow keys, hold E to crack the vault and grab loot, Space to dash, P to pause, M to mute.
